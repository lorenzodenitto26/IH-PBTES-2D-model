## Overview

This repository contains the numerical implementation used and developed within the Master's thesis *Two-Dimensional Modelling and Performance Analysis of an Induction-Heated Packed-Bed Thermal Energy Storage System*.

The work builds upon the reference Induction-Heated Packed-Bed Thermal Energy Storage (IH-PBTES) framework proposed by Famiglietti and Abbas and extends the original lumped formulation towards a spatially resolved two-dimensional axisymmetric model.

The developed numerical framework includes:

- a two-dimensional axisymmetric representation of the packed-bed domain;
- calculation of the spatial magnetic-field distribution generated by a finite induction coil;
- spatially distributed hysteresis and eddy-current heat-generation terms;
- temperature-dependent thermophysical and electromagnetic properties of magnetite;
- a transient two-dimensional thermal model for the charging phase;
- thermal losses through the lateral, top and bottom boundaries;
- an air-based packed-bed discharge model using temperature-dependent air properties, the Gunn heat-transfer correlation and a cell-by-cell NTU formulation;
- repeated charge-discharge simulations with preservation of the residual packed-bed temperature distribution between consecutive cycles;
- comparison of charging strategies based on the same cumulative electrical-energy input and on the same final mean packed-bed temperature.

## Running the Model

The Python modules, the Jupyter notebook and the two LangArc `.tsv` input files should be kept in the same project directory.

The main analysis workflow is contained in:

`IHTES_analysis_2D.ipynb`

The notebook imports the numerical modules, defines the material properties, geometrical parameters, computational mesh and operating conditions, executes the investigated simulation cases and performs the corresponding post-processing.

The principal charging model is implemented in:

`class_IHTES_2D_Tdep.py`

The discharge routines are provided by:

`discharging_model.py`

Repeated charge-discharge simulations are implemented in:

`cycles_same_energy_input.py`

and:

`cycles_same_Tmean_target.py`

## Numerical Framework

The numerical development follows the progression adopted in the Master's thesis.

The reference lumped model is first extended to a two-dimensional axisymmetric domain in which the magnetic field generated by the finite induction coil is evaluated as a function of radial and axial position.

The spatial magnetic-field distribution is then used to construct local hysteresis and eddy-current heat-generation terms. Temperature-dependent thermophysical and electromagnetic properties are evaluated locally and updated during the charging transient.

The resulting temperature field is subsequently used as the initial thermal condition of the discharge model. During discharge, ambient air enters the packed bed from both ends and flows towards the central outlet plane. The solid phase retains its two-dimensional transient description, while the air temperature is propagated cell-by-cell through the packed bed.

For repeated operation, the residual temperature distribution obtained at the end of discharge is reconstructed over the full packed-bed domain and used as the initial condition of the following charging phase.

## Reference Model

The numerical framework developed in this thesis originates from the IH-PBTES model proposed by:

A. Famiglietti and R. Abbas,  
**"A novel induction-heated packed bed integrating power-to-heat conversion and thermal energy storage for industrial process heat: a technical viability analysis,"**  
preprint, 2026.  
DOI: 10.2139/ssrn.6259851

The reference implementation provides the starting lumped formulation. The two-dimensional electromagnetic and thermal extensions, the introduction of temperature-dependent properties, the discharge formulation and the repeated charge-discharge procedures are documented in the Master's thesis and in the corresponding modules contained in this repository.
